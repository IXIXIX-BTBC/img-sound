Bolt Quake 写真シンセ
写真の上をドラッグすると、その範囲だけで数えます(クリックで解除)。マス目をクリックすると、その音になったピクセルが光ります

写真の一覧クリックで切り替え / ▶=選んで C4 で鳴らす / 数字キー 1〜9 で弾きながら切り替え / ここにドロップでも追加
写真の読み方全モード共通(同じ写真はどのモードでも同じ音名で読む)

色相 → 音名(色相環1周=12半音)/ 明るさ → オクターブ(暗い=低い)/ 色の濃さ → 強さ。灰色に近いピクセルは鳴りません。

ループシーンを順に=気に入った写真+範囲(シーン)を順にたどる(各シーンの前半はとどまり、後半で次へ)。さまよう=スタートの範囲から、パーリンノイズで範囲の位置と広さが変わり続ける。鍵盤はループの上に重ねて弾けます。
1周

スタート=今選んでいる範囲(選んでいなければ写真の真ん中40%)。そこから範囲の位置と広さがゆっくり変わり続けます。保存したシーンがあれば、ときどきそこへ立ち寄ります(別の写真のシーンなら写真ごと移ります)。音は3秒ごとに作ってなめらかにつなぎます。

山の強調を上げると、多い色だけが残ってはっきりした和音に。下げると、少ない色まで鳴って厚く濁ります。近い音をまとめる=耳が濁りとして感じる幅(高さごとに違う)のうち、この割合より近い成分を、強い方に1つにまとめます。近い音同士のうなり(キリキリ・ウワンウワン)が減ります。0=まとめない。

響き

一番強い成分を基準の音にして、ほかの成分の音程を寄せます。和音より=選んだ和音の純正な音程へ(うなりのない澄んだ響き、近い音どうしは1つにまとまる)。不協和音より=短2度・増4度・長7度へ寄せ、近い音どうしを少しずらしてこすれ合わせる。

成分の素材

各成分を、その色が一番多い行(写真上の点線)の明るさを1周期として読んだ波形で鳴らします。

波形の倍音の数
サインを混ぜる

倍音の数: 少ない=丸くやわらか / 多い=写真の細かい明暗まで入り、明るくざらつく。
行に模様のくり返しがあると、その回数倍の高さが強く鳴り、色の音程が弱まります。サインを混ぜると色の音程が保たれます。

ノイズ(成分の太さ)

各成分のまわりに、その高さだけの細い息のようなノイズをまとわせます。色にばらつきがある成分ほど太く(息っぽく)、均一な色ほど細く(澄んだ音)。

ノイズの量と太さも、成分の行のザラつきで揺れます(成分の揺らぎとは別の所を読むので、ずれて動く)。揺らぎの「速さ・音ごとの速さの違い・速さのうねり」が共通でかかります。揺らぎを「なし」にしても、ここは働きます。

揺らぎ(写真のザラつきから)

各成分が、自分の行(その色が一番多い行)の明暗を読んで揺れます。行の大きな明暗の起伏=ゆっくりしたうねり、細かいザラつき=小さく速い震え。ピッチと音量の両方が揺れます(1セント=半音の1/100)。

音ごとの速さの違い: 行がザラついている音ほど速く震える(0%=全部同じ速さ)。速さのうねり: 行の明るい所に差しかかると震えが速くなる(0%=一定の速さ)。震えは隣の行へ順に移りながら読むので、同じパターンをくり返しません。
そろい具合: 100%=全部の成分が一緒に揺れる(1つの物が揺れる)/ 0%=成分ごとにばらばら(きらめく)。

写真の形の効き

打鍵感=A を短く・D を短め・S を下げる。アンビエント=A を長く・S を上げる。写真の形(時間の形)は、この形に掛け合わせて揺れや移り変わりになります。
